# USB Screen — экран телефона на ПК и управление им по USB-кабелю

Окно на Linux показывает экран Android-телефона; мышью и клавиатурой ПК им можно управлять.
Картинка идёт по кабелю через `adb forward`, поэтому быстро (десятки кадров в секунду).

## Linux
    sudo apt install adb python3-gi python3-gi-cairo python3-cairo gir1.2-gtk-3.0
    python3 viewer.py

## Android
1. Включите «Отладку по USB»: Настройки → О телефоне → 7 раз тапнуть «Номер сборки» → Для разработчиков → Отладка по USB.
2. Подключите кабель; на телефоне разрешите этот компьютер (галочка «всегда разрешать»).
3. Поставьте APK. Если «Спец. возможности» серые: Настройки → Приложения → USB Screen → ⋮ → «Разрешить ограниченные настройки».
4. В приложении: «Включить управление» → включите USB Screen в списке служб.
5. «Начать трансляцию» → подтвердите запись экрана → на экране появится PIN.
6. На ПК запустите viewer.py, введите PIN в окне и нажмите Enter (или сразу: `python3 viewer.py 123456`). Если что-то не так, причина показывается в строке статуса и во всплывающем окне.

## Окно на ПК
Окно без системной рамки: телефон со скруглёнными углами и стеклянная панель кнопок под ним (◀ Назад, ● Домой, ▣ Недавние, ☰ Шторка, 720p — смена качества). В левом верхнем углу экрана — fps.
- тащить за рамку телефона, панель кнопок или пустое поле — переместить окно
- тянуть за края и углы — изменить размер (пропорции сохраняются); Ctrl + колесо — увеличить/уменьшить
- правая кнопка на рамке/панели — меню «Закрыть»; Ctrl+Q — выход
- для прозрачных углов нужен включённый композитинг (в Mint/Ubuntu он включён по умолчанию)

## Управление
- Мышь = палец: клик — тап; зажать и вести — свайп; колесо — прокрутка
- Правая кнопка — «Назад», средняя — «Домой»; панель сверху: Назад / Домой / Недавние / Шторка
- Клавиатура ПК печатает в активное поле ввода на телефоне (любой язык)
- «Качество»: низкое 480p / среднее 720p / высокое 1080p (по ширине)

## Безопасность
Приложение слушает только 127.0.0.1 телефона, подключиться можно только с проверкой PIN
(после 5 неверных попыток PIN меняется). PIN действует, пока идёт трансляция.

## Протокол
Телефон → ПК: [тип=1][длина u32 BE][JPEG].  ПК → телефон, по строке (первая — `auth PIN`):
tap x y ms | swipe x1 y1 x2 y2 ms | back | home | recents | notif | t <hex…> | bs | enter | q 1..3  (x, y — доли 0..1)
